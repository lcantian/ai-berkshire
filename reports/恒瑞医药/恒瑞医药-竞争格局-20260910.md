### 1.3 关键观察（观点）

**恒瑞的相对位置**：
1. **盈利能力最强**：恒瑞63.37亿元归母净利润远超其他6家之和（含百济神州-49.78亿、信达-0.95亿、君实-12.81亿，合计-63.54亿）
2. **创新药占比中游**：恒瑞>50%介于翰森（77.3%）和石药/中生（30-42%）之间，但绝对体量最大（138.92亿元）
3. **研发投入第二**：恒瑞82.28亿元，仅次于百济神州141.55亿元
4. **销售费用控制较好**：73.31亿元（费用率26.2%），远低于百济神州的107.97亿元（费用率39.6%）

**反面观点（不确定性）**：
- 创新药占比口径不一：恒瑞"创新药销售"含税口径，与百济神州按产品口径相比可能虚高
- 销售费用率下降空间有限：随着创新药队伍扩张，销售费用绝对额仍将增长

## 2. 恒瑞核心管线竞争力分析

### 2.1 管线总览

**截至2024年底**：
- 已上市：**19款1类创新药 + 4款2类新药**
- 累计纳入国家医保：**106个产品**（其中**15款创新药**进入医保）
- 90多个自主创新产品在临床开发
- 约400项临床试验在国内外开展
- 2024年取得创新药临床批件112个

**未来3年（2025-2027）预计获批创新成果**：
- 2025年：11项（含HER2 ADC 瑞康曲妥珠单抗 SHR-A1811）
- 2026年：13项
- 2027年：23项
- **合计47项**

#### 2.2.2 ADC平台：核心战略高地

**恒瑞ADC布局**：
- SHR-A1811（瑞康曲妥珠单抗，HER2 ADC）：**2024年9月NDA获NMPA受理**，用于HER2突变型非小细胞肺癌；**国内首个国产ADC的NDA**
- 2025年获批预期高，III期HORIZON-Breast01临床数据积极
- TROP2 ADC等多个靶点推进中
- ADC研发沉淀10年以上

**AACR 2025（2025年4月）**：
- 恒瑞公布SHR-A1811等20+创新管线临床数据
- 覆盖乳腺癌、胃癌、胆道癌等多个瘤种

**对标第一三共DS-8201（Enhertu）2024年全球销售37.54亿美元**（同比+46%-52%），已获批60+国家，累计销售73.7亿美元，进入19项NCCN指南，2024年纳入中国医保。

**国内ADC竞争格局**：
- 科伦博泰：与默沙东合作多笔ADC交易（TROP2 ADC SKB264领跑）
- 百利天恒：BL-B01D1（EGFR×HER3 ADC）与BMS达成84亿美元总交易
- 宜联生物：与罗氏达成ADC合作
- 翰森制药：B7-H3 ADC（HS-20093）、B7-H4 ADC（HS-20089）授权GSK

**观点**：恒瑞ADC平台在国内属于第一梯队，但出海进度落后于科伦博泰（默沙东合作）和百利天恒（BMS合作）。

### 2.5 慢病/糖尿病：GLP-1布局

## 3. 政策与行业前景

### 3.1 国家医保谈判（NRDL）2024年结果

**核心数据**：
- 谈判时间：**2024年10月27日-30日**，北京
- 参与药品：**162个**
- **创新药占比超60%**
- 新版目录实施：**2025年1月1日**

**整体成效**：
- 2024年医保目录新增 **91种药品**，其中 **38种为创新药**（创历年新高）
- **33种"当年获批、当年纳入"**
- 2018-2024年医保谈判新增药品协议期内销售额超 **5,400亿元**

**恒瑞参与情况**：
- 参与产品数量为**历年最多**
- 涉及产品：达尔西利（乳腺癌，再次谈判）、瑞维鲁胺（前列腺癌）、卡瑞利珠单抗（PD-1，续约/新增）、阿帕替尼、多个影像和血液制品

**政策趋势**：
- 创新药从上市到纳入医保的时间从5年缩短至1年
- 设立丙类药品目录，以创新药为重点
- 全链条支持创新药发展实施方案（2024年7月5日国务院常务会议审议通过）

### 3.2 集采（VBP）第十批（2024年12月）

**核心数据**：
- 开标时间：**2024年12月12日**
- 439家企业申报，778个产品
- **62个品种**采购成功，234家企业的385个产品中选
- 执行时间：**2025年4月起**

**典型案例：多美素（盐酸多柔比星脂质体注射液）**
- 中标企业：**石药欧意药业**（非恒瑞！）
- 中标价格：**98元/支**（限价降幅约89%）
- 较京津冀"3+N"联盟集采（3,503.7元）降幅**97%**

### 3.3 DRG/DIP医保支付改革

**DRG/DIP 2.0版分组方案（2024年7月发布）**：

**核心机制**：
1. **特例单议机制**：住院时间长、医疗费用高、使用新药/新耗材/新技术等不适合按DRG/DIP标准支付的病例，医疗机构可自主申报
   - 上限：DRG出院总病例的**5%**或DIP出院总病例的**5‰**
   - 2025年实际数据：全国申请267.4万例，通过232.4万例（通过率86.9%），医保基金支出约644.7亿元
2. **除外支付机制**：对符合条件的新药耗新技术，在应用初期按项目付费或权重加成
   - 北京2024年12月发布首批DRG付费新药新技术除外支付名单
3. **医保基金直接结算**：海南、广西等9省已推进
   - 回款周期从平均**6个月减少到不到30天**
   - 目标：2025年全国基本实现集采药品/国谈药直接结算；2026年全国全面实现

**DRG/DIP 3.0版分组方案**：
- 2025年8月开展调整工作
- 2025年全国职工/居民医保次均住院费用较2024年分别下降4.73%/0.94%

**对创新药的实际利好**：
1. 销售放量加速：2024年38种创新药入医保（创历年新高）
2. 现金流改善：直接结算降低资金成本
3. 解决"进院难"：除外支付 + 国谈药品单独激励（浙江2024年DRG清算兑现国谈药品单独激励6亿元）

### 3.4 FDA对中国创新药出海政策

**关键政策框架**：
1. **FDA突破性疗法认定（BTD）**：
   - 严重或危及生命疾病的初步临床证据显示实质性改善
   - 60天内回复，享受加强指导、滚动审评、优先审评
2. **FDA-EMA平行科学建议（PSA）项目**：BTD+PRIME双重认定产品可申请
3. **NMPA突破性疗法程序**：依据NMPA-No82-2020，可在I/II期临床试验期间申请

**中国创新药FDA获批案例（2024-2025）**：
- **康方生物 PENPULIMAB-KCQX**：FDA孤儿药 + Fast Track认定
- **迪哲医药 ZEGFROVY/SUNVOZERTINIB**：FDA优先审评 + 加速批准

**观点**：
1. **中美双报路径日趋成熟**：2024-2025年中国创新药在FDA的BTD和获批数量明显增加
2. **恒瑞的相对短板**：相比百济神州（泽布替尼、替雷利珠已在欧美获批）、信达生物（与礼来深度合作）、君实生物（特瑞普利美国LOQTORZI获批），恒瑞的FDA自主申报进度较慢
3. **恒瑞的应对策略**：通过License-out（GSK 5亿美元、Merck KGaA、Kailera等）借助MNC的海外申报能力

1. **国内创新药龙头地位稳固**：2024年净利润63.37亿元（+47.3%）+ 创新药销售138.92亿元（+30.6%）+ 研发投入82.28亿元（+33.8%），均创历史新高
2. **创新药占比超50%**：从仿制药企成功转型为创新药企，2025H1占比进一步提升至60.8%
3. **BD出海第一梯队**：近三年8笔海外授权，2025年GSK 5亿美元单笔交易创历史新高
4. **管线储备深厚**：未来3年（2025-2027）47项创新成果预计获批

**核心竞争优势**：
1. 销售费用控制能力（费用率26.2% vs 百济神州39.6%）
2. 商业化效率（销售队伍6800人支撑138.92亿元创新药销售）
3. 全管线布局（PD-1 + ADC + GLP-1 + 多靶点小分子）
4. 现金流充裕（2024年净利润63.37亿元 vs 创新药销售现金流入）

**核心劣势/风险**：
1. **PD-1出海进度落后**：替雷利珠已在欧美多国获批，卡瑞利珠主要依赖韩国Crystal Genomics合作
2. **ADC商业化落后**：科伦博泰SKB264已率先商业化，恒瑞SHR-A1811 2025年才有望获批
3. **GLP-1进度落后**：信达IBI362已2025年获批，恒瑞HRS-7535仍处III期
4. **仿制药业务持续萎缩**：2024年-8.79%，长期面临集采压力

### 6.2 风险提示（不确定性）

1. **行业政策风险**：医保谈判降价幅度、集采常态化推进
2. **研发失败风险**：90+个临床在研产品中可能存在失败案例
3. **海外授权依赖风险**：BD出海占收入比重上升，但单笔交易首付款较高导致非经常损益波动大

5. **GLP-1赛道竞争白热化**：诺和诺德、礼来、辉瑞（口服）、罗氏等海外巨头均加大投入
