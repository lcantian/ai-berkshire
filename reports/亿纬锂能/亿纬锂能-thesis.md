## 关键观察项与触发条件

### 加仓信号（任意1条触发）

1. **价格信号**：股价跌至40元以下（PB<1.70x, 2026E PE<12x）← **最接近触发（10/22盘中41.21元）**
2. **结构性改善**：储能电池毛利率回升至15%+ ← **Q3未披露，无法验证**
3. **现金流改善**：经营性OCF连续两季度为正且>50亿 ← **未达标（9M仅16.98亿）**
4. **诉讼消除**：LG专利诉讼胜诉或达成有利和解 ← 未达标
5. **库存去化**：存货周转天数回归70天以下 ← ✅ **已满足（56.5天）**

### 减仓信号（任意1条触发）

1. **估值过热**：股价涨至65元+（PE>19x）← 未触发
2. **OCF持续恶化**：连续两季度OCF为负且缺口扩大 ← 未触发（Q3已转正）
3. **存货激增**：库销比突破0.4（即存货/单季收入）← ❌ **早已触发且持续恶化**（2025末0.500→H1 0.617→Q3 0.640）
4. **诉讼败诉**：LG专利诉讼一审败诉 ← 未触发
5. **担保问询**：证监会就担保占比超线发出监管问询函 ← 未触发

### 论文破裂信号（任一触发）

1. **储能业务根本性恶化**：储能毛利率连续4季度低于10%且市占率跌出全球前3
2. **财务造假**：审计意见非标 / 关键数据无法勾稽
3. **控股股东大幅减持 / 质押暴雷**（当前控股股东质押率40.4%，合计占总股本13.51%）
4. **固态电池颠覆**：2027年宁德等竞品全固态商业化挤压亿纬大圆柱差异化空间
