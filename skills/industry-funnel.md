# 行业漏斗筛选：从全市场到 3 家的价值投资精选流程

对 $ARGUMENTS 行业/方向执行漏斗式价值投资筛选，从全市场扫描逐层精选到 3 家终选标的。

> **唯一口径见 `skills/four-factor-framework.md`。** 本 skill 只写漏斗流程；四因素的定义、阈值、打分公式、否决线以该文件为准。
> **分工原则**：生意模式 + 护城河 = 是否值得跟踪（入池资格）；周期 + 估值 = 什么时候买、买多少（时点与仓位）。
> **漏斗的执行顺序就是这个顺序，不能反。**

## 适用场景

当你说出一个行业或投资方向（如"AI 算力"、"创新药"、"机器人"），想要：
1. 不遗漏任何重要标的（含 A 股、港股、美股、未上市候选）
2. **先用质量门槛**过滤掉"故事股"和生意质量不足的公司
3. 把精力聚焦到真正值得跟踪的 3 家头部
4. **再用周期与估值**决定这 3 家什么时候买、买多少
5. 每层有明确的留/弃标准，可复盘可追溯

与 `industry-research` 的区别：
- `industry-research` 偏重产业链结构与全景，环节切片
- `industry-funnel` 偏重个股筛选漏斗，从全市场逐层精选到 3 家

两者可以互补：先用 `industry-research` 看清产业链格局，再用 `industry-funnel` 精选标的。

## 漏斗结构总览

```
第一层：全市场扫描        30-60 家   （活跃度+涨幅+市值前 30 的并集）
        ↓ 质量门槛：6 条淘汰指标 + 1 条观察指标 + 护城河 ≥★★★
第二层：A/B 通道           ≤ 12 家   （A 通道 = 值得跟踪；B 通道只记录"为什么便宜"）
        ↓ 精细分析（只看 A 通道）
第三层：质量层分层          ≤ 12 家   （生意质量★ + 护城河★ → A1/A2/A3）
        ↓ 终选（组合互补性，不按估值排序）
第四层：四大师深度分析        3 家     （每家 800-1200 字，巴芒段李四视角）
        ↓ 周期定位 → 估值 → 三层打分
输出：两家结论（是否值得跟踪 / 什么时候买买多少）+ 操作信号 + 仓位建议
```

**三条硬规则**：

1. **估值不进初筛。** PE 高低不是"是否值得跟踪"的标准；低 PE 只说明"便宜"，不说明"好"。
2. **周期不进初筛。** 周期顶部不取消跟踪资格，只封顶最终星级（≤★★★）且不新建仓；周期底部也不加分。
3. **B 通道不得进入第三、四层。** 不做估值、不给仓位（含期权仓位），只进"被排除的便宜货"表。

每层"过滤掉的标的"必须留下淘汰理由，不能黑箱。

## 第一步：全市场扫描入口

### 1.1 活跃股票定义（三类并集）

**A 类 - 成交活跃度**：
- 近 30 天日均成交额排名行业前列（A 股/港股/美股各自取前 30）

**B 类 - 涨幅榜**：
- 近 30 天涨幅前 20
- 近 90 天涨幅前 20
- 两者并集

**C 类 - 市值锚定**：
- 行业内市值前 30（无论涨跌）

最终扫描池 = A ∪ B ∪ C，预期 30-60 家。

### 1.2 必须搜索的市场

| 市场 | 来源建议 |
|------|---------|
| A 股（沪深） | 同花顺/东方财富行业板块、通达信 |
| 港股 | 富途/同花顺港股、HKEX 行业分类 |
| 美股 | NASDAQ/NYSE 行业 ETF 持仓、Yahoo Finance |
| 国际市场 | 日韩台欧的相关公司不能漏（特别是半导体、电子） |
| 未上市公司 | 单列"未来 IPO 候选"小节，注明最新估值与潜在 IPO 时间 |

### 1.3 输出格式

| 公司名 | 代码 | 市场 | 市值 | 主业一句话 | 该行业占比 | 入选类别(A/B/C) |
|-------|------|-----|------|----------|-----------|----------------|

**关键自查**：
- 行业占比 < 30% 的"沾边股"要谨慎，标注"非纯正标的"
- 中国/亚洲市场不要因英文资料少而漏掉
- 小市值公司不要因为 AI 偏好龙头而漏

## 第二步：质量门槛粗筛 → A/B 通道（≤ 12 家）

> **本层只回答"是否值得跟踪"，不回答"贵不贵""周期在哪"。**
> 对第一步的 30-60 家公司，逐家执行 `skills/quality-screen.md` 的 6 条淘汰指标 + 1 条观察指标，并完成护城河快评。

### 2.1 6 条淘汰指标 + 1 条观察指标

| # | 指标 | 淘汰线 | 放宽条件 |
|---|------|---------|---------|
| ① | 10 年平均 ROE | < 8% | 豁免 A（战略投入期） |
| ② | 5 年累计自由现金流 | < 0 | — |
| ③ | 利息覆盖倍数（EBIT/利息） | < 2 倍 | 银行/保险不适用 |
| ④ | 长期毛利率 | < 15% | 豁免 B / C |
| ⑤ | 经营现金流 / 净利润（5 年均值） | < 0.7 | — |
| ⑥ | 长期净利率 | < 5% | 豁免 B / C |
| ⑦ | **5 年经济稀释（观察项，不淘汰）** | 累计"吸收投资收到的现金" ÷ 期末归母净资产 > 20% → 记为资本配置观察项 | 送转股/拆股不算稀释 |

**豁免规则**：
- **A（战略投入期）**：上市不足 10 年 + 毛利率 > 30% + 最近 2 年经营现金流为正 → 豁免①。
- **B（主动低利润率）**：毛利率 > 30% + 近 2 年净利率回升至 5% 以上或明确上升 → 豁免⑥。
- **C（高周转薄利）**：ROE > 20% + 经营现金流/净利润 > 1.0 + 会员/平台/高周转模式 → 豁免④⑥。

### 2.2 生意质量★ 快评

按 `skills/four-factor-framework.md` 的评分标准打分（★1-5）：

| 星级 | 条件 |
|---|---|
| ★★★★★ | 6 条淘汰全过，且 ROE≥20%、毛利率≥40%、OCF/净利润≥1.0、资本开支/收入≤5%、有清晰定价权来源 |
| ★★★★☆ | 6 条全过，且至少 3 项优秀（ROE≥15%、毛利率≥30%、OCF/净利润≥0.8、净利率≥10%、资本开支/收入≤10%） |
| ★★★☆☆ | 6 条全过但多数指标平庸；或 1 条靠豁免通过 |
| ★★☆☆☆ | 1–2 条未过且只能部分豁免；或趋势明显恶化 |
| ★☆☆☆☆ | 多条未过、无法豁免；或 FCF 持续为负 |

### 2.3 护城河快评

五类护城河逐一打分（★1-5）：品牌/定价权、转换成本/用户黏性、网络效应、规模效应、技术/牌照/资源壁垒。

> **综合分取法：护城河★ = 五类中最高的单类得分，不取平均。** 必须写清是哪一类、证据是什么。

**门槛**：至少 1 类 ≥★★★ → 才有资格进入 A 通道；核心仓位需 ★★★★ 及以上（本层不评核心仓位）。

### 2.4 A / B 通道与 A 通道细分

| 通道 | 条件 | 后续处理 |
|---|---|---|
| **A 通道（值得跟踪）** | 6 条淘汰全过（含豁免）**且**至少 1 类护城河 ≥★★★ | 进入第三、四层；按质量层分 A1/A2/A3 |
| **B 通道（不值得跟踪）** | 任一淘汰指标不过且不可豁免，**或**五类护城河全部 <★★★ | **不做估值、不进组合**；只进"被排除的便宜货"表 |

> **质量层 =（生意质量★ + 护城河★）÷ 2**

| 层级 | 条件 | 可竞争仓位 |
|---|---|---|
| **A1** | 质量层 ≥4.0，且生意质量≥4★、护城河≥4★ | 核心 / 卫星：质量层≥4.5 且估值调整 0 → 可竞争核心；4.0–4.4 → 最高卫星 |
| **A2** | 质量层 3.5–3.9 | **只观察（0 仓位）**：上限 ★★★，达不到卫星的 ★★★★ |
| **A3** | 质量层 <3.5 | 只观察；有明确催化剂且最终星级≥★★ 时最多期权仓位 |

### 2.5 输出格式

| 公司 | ①ROE | ②FCF | ③利息覆盖 | ④毛利率 | ⑤OCF/NI | ⑥净利率 | ⑦经济稀释 | 最强护城河 | 生意质量★ | 护城河★ | 质量层 | 通道 | 留/弃 | 淘汰理由 |
|------|------|------|----------|---------|---------|---------|-----------|-----------|:---:|:---:|---:|:---:|------|---------|
| | | | | | | | | 品牌/转换/网络/规模/技术 | | | | A1/A2/A3/B | | |

**保留规则**：
- **A 通道**：6 条淘汰全过（含豁免）+ 至少 1 类护城河 ≥★★★ → 保留进入第三层。
- **B 通道**：任一淘汰不过且不可豁免，或五类护城河全部 <★★★ → 淘汰，写清理由，进入"被排除的便宜货"表。
- **数据不足**：不判通过也不判排除，标注"灰色地带，需补一手数据"，可保留但降级为观察。
- **周期顶部不淘汰**：只影响最终仓位（封顶 ★★★、不新建仓），不影响跟踪资格。

**目标**：A 通道保留 ≤12 家。若超过 12 家，按质量层从高到低取前 12，**不改变 A/B 判定**；不得为了凑数把 B 通道拉进来。

### 3.2 终选 3 家的选择标准

不是按打分排序选前 3，而是按"投资组合互补性"选，且**只能从 A 通道中选**：
- 至少 1 家"高确定性低弹性"（A1，巴菲特型）
- 至少 1 家"中等确定性中等弹性"（A1/A2，成长型；最终仓位由三层打分决定）
- 可选 1 家"高弹性高风险"（A3，期权型；须写明赌什么）

**硬约束**：
- **B 通道不得进入终选**，无论 PE 多低、周期多好。
- **周期顶部可以进入深度研究**，但结论只能是"观察 / 0 仓位"，不能给买入区间。
- 如果某子赛道找不到 3 家足够好的，宁可写"终选 2 家 + 1 家观察"，**不要凑数**。

## 第四步：四大师深度分析 + 周期 + 估值（3 家，每家 800-1200 字）

对终选 3 家执行四大师视角深度分析，并完成三层打分。

### 4.1 段永平视角：生意本质

- 一句话定义这家公司在做什么生意
- 这是好生意吗？为什么？
- 它的"本分"是什么？管理层有没有偏离？
- 商业模式的"持续性"在哪？

### 4.2 巴菲特视角：护城河深度

- 用五类护城河打分（★1-5），列具体证据；综合分取最高单类
- 10 年后护城河还在吗？
- 现在买入的"安全边际"在哪？

| 护城河 | 强度 | 具体证据 |
|-------|------|---------|
| 品牌/定价权 | | |
| 转换成本 | | |
| 网络效应 | | |
| 规模效应 | | |
| 技术/牌照壁垒 | | |

### 4.3 芒格视角：风险与失败模式

- 这家公司最可能怎么失败？（列出前 3 失败路径）
- 最坏情景下值多少钱？（极简估值）
- 聪明人为什么不买？（反向论证）
- 是否有道德/合规/管理层风险？

### 4.4 李录视角：文明级趋势定位

- 这家公司所在的赛道是"文明级范式转移"还是"阶段性热潮"？
- 历史上最接近的技术革命类比？
- 10-20 年后这家公司的终局？
- 是不是赢家通吃格局？

### 4.5 质量门槛结论（是否值得跟踪）

| 项目 | 结论 |
|---|---|
| 6 条淘汰指标 | 逐条通过/失败（含豁免） |
| 生意质量★ | |
| 护城河★（最强单类） | |
| 质量层 | （生意质量★ + 护城河★）÷2 |
| 通道 | A1 / A2 / A3 |
| **推荐度上限** | |

> **这一段只看生意模式 + 护城河，不看估值、不看周期。**

### 4.6 周期定位（什么时候买，仅 A 通道）

按 `skills/cycle-analysis.md` 给完整表：存货三指标、存货结构、合同负债、≥6 个单季序列（差分实算）、四象限、四档结论 + 反面论据 + 反转信号。

| 周期档位 | 约束 |
|---|---|
| 周期底部 / 上行中段 | 不额外调整，也不能上调 |
| **周期顶部** | **不得高于 ★★★☆☆；不新建仓** |
| **周期下行中段且库存未去化** | **不得高于 ★★★☆☆；不得进核心仓位** |

### 4.7 估值与三层打分（买多少）

**第一层：质量层 → 推荐度上限**

| 质量层 | 上限 |
|---|---|
| ≥4.5 | ★★★★★ |
| 4.0–4.4 | ★★★★☆ |
| 3.0–3.9 | ★★★☆☆ |
| 2.0–2.9 | ★★☆☆☆ |
| <2.0 | ★☆☆☆☆（不推荐，不论多便宜） |

**第二层：估值调整（只能 0 / −1 / −2）**

| 估值状态 | 判定条件 | 调整 |
|---|---|---|
| **显著低估** | ① 3年分位<20% 且全历史分位<30%；② 扣非/归母≥85%；③ 扣非同比>0；④ 单季年化PE<扣非PE（四条同时满足） | 0 |
| **合理** | 以上都不满足 | −1 |
| **明显高估** | ① 3年分位>70% 或全历史分位>70%；或 ② 正常化PE>3×扣非PE；或 ③ 扣非PE>80倍且扣非增速<30% | −2 |

**第三层：周期封顶（只能封顶，不能上调）**

| 周期档位 | 封顶 |
|---|---|
| 周期底部 / 上行中段 | 不封顶（也不上调） |
| 周期顶部 | ≤★★★☆☆，不新建仓 |
| 周期下行中段且库存未去化 | ≤★★★☆☆，不进核心 |

**最终星级 = min（质量层上限 − 估值调整，周期封顶）**

| 最终星级 | 仓位层级 | 占主题仓位 |
|---|---|---|
| ★★★★★ | 核心仓位 | 50–60% |
| ★★★★☆ | 卫星仓位 | 25–35% |
| ★★★☆☆ | 观察名单 | 0% |
| ★★☆☆☆ | 高风险期权 | 5–15%（仅限 A 通道 + 质量层 <3.5；A1/A2 落到 ★★ 按观察 0%） |
| ★☆☆☆☆ | 不推荐 | 0% |
| B 通道 | 不参与 | 0%（含期权） |

> **推荐度必须等于打分表算出的结果，禁止手写。**

### 5.5 信息充分度自评（必填）

## AI 研究偏见自觉（重要）

漏斗筛选过程中，AI 容易踩的坑：

| 偏见 | 表现 | 应对 |
|------|-----|------|
| 龙头偏好 | 大市值公司资料多、分析篇幅长，看起来"更好" | 按质量门槛和护城河打分，不按报告篇幅排序 |
| 英文偏好 | 美股资料丰富，A 股港股容易被低估 | 必须中英文都搜，A/H 公司不能漏 |
| 故事偏好 | 高涨幅 + 媒体热度 = 看起来更好的"AI 概念股" | 区分"AI 收入占比" vs "AI 故事占比"，看真实业务 |
| 当下偏好 | 当前财务好的公司容易入选，可能错过转型期黑马 | 用完整周期均值，不用单一年份；上市不足 5 年标注"数据窗口不足" |
| 低估值偏好 | 便宜的公司看起来"安全"，容易进组合 | **PE 不参与初筛**；便宜只在 A 通道内影响仓位 |
| 上市偏好 | 只看上市公司可能错过赛道最好的玩家 | 必须列"未来 IPO 候选"，标注估值与时间窗 |

## 输出要求

1. **报告位置**：`reports/{行业名}-funnel-{YYYYMMDD}.md`（行业报告放 reports/ 根目录）
2. **语言**：中文
3. **风格**：直接、犀利、不说废话
4. **数据**：所有数据标注来源；估计值标"估计"
5. **不预设立场**：先摆数据 → 推逻辑 → 出结论
6. **正反两面**：每个核心判断附反面论据
7. **每层留淘汰记录**：被淘汰的公司也要留名字+理由
8. **⭐ 报告开篇必须有三张表，顺序固定**：① 全市场扫描池；② 质量门槛 A/B 名单（含 A1/A2/A3）；③「被排除的便宜货」表。**没有第三张表，报告不得进入估值章节。**
9. **⭐ 终选 3 家必须给出三层打分完整推导**（质量层上限 → 估值调整 → 周期封顶），最终星级不得手写。
10. **⭐ 结论必须分开写两段**：第一段回答"这几家是否值得跟踪"（A/B + 质量层）；第二段回答"现在买不买、买多少"（周期 + 估值 + 仓位）。两段顺序不能反。

## 数据抽检（准出流程）

报告写入后，执行数据抽检，通过方可发布：

```bash
# Step 1 — 提取抽检清单（15% 随机抽样）
python3 tools/report_audit.py extract \
  --report <报告文件路径>

# Step 2 — 对清单每项从可靠信源取数（参见 skills/financial-data.md）

# Step 3 — 输出准出/打回判决
python3 tools/report_audit.py verdict \
  --results '<填好的JSON>' \
  --report <报告文件名>
```

**【准出】** 全部通过 → 报告可发布；**【打回】** 有不通过 → 修正后重审。
