# 行业投资研究：产业链全景扫描 + 四大师个股分析框架

对 $ARGUMENTS 行业进行系统化产业链投资研究。

## 研究目标

从一个投资主题/逻辑链出发，完成：
1. 验证投资逻辑链的每一个环节
2. 绘制完整产业链全景图
3. 扫描全球所有上市公司（A股/港股/美股/国际）
4. 对每个细分环节的头部公司执行四大师框架分析
5. 输出行业级投资组合配置建议

---

## ⭐ 四因素分工（最高纪律，先于一切分析）

> **唯一口径见 `skills/four-factor-framework.md`。本节只摘录行业研究必须执行的部分，不得另立阈值。**

**排序不可颠倒：① 生意质量 → ② 护城河 → ③ 周期 → ④ 估值。**

**生意质量 + 护城河 = 是否值得跟踪；周期 + 估值 = 什么时候买、买多少。**

| 因素 | 要回答的问题 | 作用 | 不通过的处理 |
|---|---|---|---|
| ① 生意质量 | 这门生意本身赚不赚钱、赚的是不是现金、资本回报率高不高 | **决定是否值得跟踪** | **直接排除**，不进入估值环节 |
| ② 护城河 | 十年后这门生意还属不属于它 | **决定是否值得跟踪** | 五类全部 <★★★ → B 通道；核心仓位需 ★★★★ |
| ③ 周期 | 现在处在周期哪一段 | **决定什么时候买 + 一票否决** | **一票否决**（周期顶不建仓），但不能把平庸生意变成好投资 |
| ④ 估值 | 现在买要付多少钱 | **决定买多少、什么价格买** | 只决定"买多少、什么时候买"，不能上调推荐度 |

**⭐ 本框架最硬的一条：估值便宜 + 商业模式一般 = 不会有非常好的结果。**

原因不是"便宜没用"，而是**便宜通常有原因**：

- **资本回报衰减**：长期 ROE 低于资本成本的公司，PE 再低也只是"慢性失血得慢一点"；E 会继续掉，低 PE 是对未来的正确贴现。
- **没有定价权**：毛利率被上游与下游同时挤压的公司，今天的低 PE 建立在明天更低的利润上。
- **纸面利润**：经营现金流长期显著低于净利润的公司，估值折价是对"拿不到现金"的合理定价。
- **生意本身在收缩**：行业需求见顶、替代技术成熟，便宜是清算价而非错价。

**因此行业分析要回答的第一个问题不是"哪个最便宜"，而是"哪个生意最好"。**

**三条推导纪律**：
1. 组合的核心仓位**只能**来自「生意质量 ★★★★ 及以上 且 护城河 ★★★★ 及以上」的标的；
2. 周期与估值只能在这个范围内做**排序与仓位加减**，不能把范围外的标的拉进来；
3. **若整个行业没有公司通过质量门槛，正确结论是"这个行业现阶段不值得配置"**，而不是勉强挑几个便宜的凑数。

## 第一步：投资逻辑链构建与验证

### 1.1 画出逻辑链
用箭头链路表达从"底层趋势"到"受益标的"的因果关系，例如：
```
底层趋势 A
    → 导致需求 B
        → 创造瓶颈/刚需 C
            → 受益产业链 D
```

### 1.2 逐环节验证
对逻辑链的每个箭头提出质疑并寻找证据：

| 环节 | 核心假设 | 验证方式 | 数据来源 |
|------|---------|---------|---------|
| A→B | | 搜索行业数据/预测 | |
| B→C | | 搜索供需分析 | |
| C→D | | 搜索实际案例/签约 | |

### 1.3 寻找"已发生的验证事件"
列出支撑该逻辑链的**已签约/已落地的真实商业事件**（而非预测），例如大公司的采购协议、政策文件、行业报告等。

## 第二步：产业链全景图绘制

### 2.1 绘制产业链结构
将行业拆解为上游→中游→下游→辅助环节，例如：
```
上游：原材料/资源开采 → 材料加工/提纯
中游：核心设备制造 → 系统集成/工程建设 → 新技术研发
下游：运营/服务 → 终端客户
辅助：检测/认证 → 维护服务 → 金融工具（ETF/信托）
```

### 2.2 识别每个环节的"生意特征"
对每个环节标注：

| 环节 | 商业模式 | 毛利率区间 | 竞争格局 | 壁垒类型 | 周期性 |
|------|---------|-----------|---------|---------|--------|
| | 卖资源/卖设备/卖服务/收租 | | 垄断/寡头/充分竞争 | 资源/牌照/技术/规模 | 强/中/弱 |

### 2.3 标记"卡脖子环节"
识别产业链中供给最紧张、替代最难、利润率最高的环节——这些往往是最佳投资标的所在。

### 2.4 环节级"生意质量"排序（先于选股）

同一个产业链里，不同环节的生意质量天差地别：**卖资源的赚价格、卖设备的赚别人的资本开支、卖服务的赚续费**。

**必须先给环节排序，再在好环节里选公司**——在差环节里选到最好的公司，长期回报通常也不如在一个好环节里选到普通的公司。

| 环节 | 毛利率 | 净利率 | 10 年平均 ROE | 经营现金流/净利润（5 年均） | 资本开支/收入 | **定价权来源** | 生意质量★ | 排名 |
|---|---:|---:|---:|---:|---:|---|---:|---:|

**判读要点（先看定价权来源，再看数字）**：
- **定价权来源只有四种算数**：品牌、转换成本、网络效应、成本/规模优势。说不出来源的，就是没有定价权。
- **毛利率 < 15% 且无成本优势** = 加工组装生意，长期赚不到超额回报。
- **经营现金流/净利润长期 < 0.7** = 利润是纸面的，赚到的钱在应收和存货里。
- **资本开支/收入 > 15% 且产品无差异化** = 赚的钱又投回机器，股东永远拿不到自由现金流。
- **ROE 高但靠杠杆** = 质量是借来的，利率或需求一变就还回去。

## 第 2.5 步：⭐ 质量门槛（Quality Gate，强制）

> 工具：`skills/quality-screen.md` 的 6 条淘汰指标 + 1 条观察指标 + 3 条豁免规则。**这一步的唯一作用，是把"便宜但平庸"的标的挡在估值分析之外。**

### 2.5.1 两条通道与 A 通道细分

对第三步扫描出的全部候选（Tier 1–3 必做，Tier 4 可抽样）逐家过筛：

| 通道 | 条件 | 后续处理 |
|---|---|---|
| **A 通道（值得跟踪）** | 6 条淘汰指标全部通过（或触发豁免规则）**且**五类护城河中至少 1 类 ≥ ★★★ | 进入第四步四大师分析 + 周期 + 估值；按质量层分 A1/A2/A3 |
| **A1** | 质量层 ≥4.0（**不再要求生意质量与护城河各自≥4★**；护城河下限仍为 A 通道的 ★★★） | ≥4.5 显著低估→核心；≥4.5 合理→卫星；4.0–4.4 显著低估→卫星；4.0–4.4 合理→小仓 10–15%；高估→0 |
| **A2** | 质量层 3.5–3.9 | **可建试探仓（≤10% 主题仓位）**：仅当显著低估且周期不在顶部/下行未去化；合理及以上一律 0% |
| **A3** | 质量层 <3.5 | 只观察；**显著低估 + 明确催化剂**时最多期权仓位 ≤5%；合理及以上一律 0% |
| **B 通道（不值得跟踪）** | 任一淘汰指标不通过且无法豁免，**或**五类护城河全部 < ★★★ | **不做估值、不进组合（含期权仓位）**，只记录"它为什么便宜" |

### 2.5.2 三类必须警惕的"便宜但平庸"

| 类型 | 特征 | 为什么低 PE 是陷阱而不是机会 |
|---|---|---|
| **资本回报衰减型** | 10 年平均 ROE < 8%，PE 8–12 倍 | PE 低是因为 E 还要继续掉，不是市场算错了 |
| **纸面利润型** | 经营现金流/净利润 < 0.7，应收+存货占收入比重高 | 赚的钱压在客户和仓库里，不在账上 |
| **无定价权型** | 毛利率长期 < 15% 或持续下滑，客户集中度高 | 上下游同时挤压，毛利率没有底 |

### 2.5.3 报告必须单列「被排除的便宜货」表

| 公司 | 代码 | PE(TTM) | 扣非PE / 正常化PE | 门槛失败项 | 排除理由（对应哪类陷阱） | 若强行买入最可能亏在哪 |
|---|---|---|---:|---:|---|---|

**这张表是防止 AI 用低估值凑组合的关键约束——不写这张表，等于没有执行质量门槛。**

## AI研究偏见自觉：行业研究的特殊陷阱

行业研究中，AI数据偏见会以独特方式放大：

**行业级偏见**：
| 偏见类型 | 表现 | 应对 |
|---------|------|------|
| 成熟行业偏好 | 传统行业（银行/能源/消费）资料极多，AI分析看起来"更确定" | 确定性来自商业模式，不来自研报数量 |
| 新兴行业低估 | 新行业（AI应用/合成生物等）资料少，AI分析偏保守 | 用"终局思维"而非"当前数据"判断行业价值 |
| 龙头偏好 | 大公司资料远多于小公司，AI天然倾向推荐龙头 | 小公司可能有更好的风险回报比，不要因为AI分析篇幅短就忽略 |
| 上市偏好 | 只扫描上市公司会遗漏产业链中的关键未上市玩家 | 必须搜索未上市公司，标注"未来IPO候选" |
| 英文偏好 | AI对英文资料的处理能力更强，可能低估中国/亚洲市场玩家 | 必须同时搜索中英文信息源 |

**产业链扫描中的反偏见措施**：
1. 对每个环节，不仅列出"AI容易找到的公司"，还要主动搜索"冷门但可能优质的标的"
2. 对信息稀缺的小市值公司，不因分析篇幅短就降低推荐度——用核心问题（生意本质、护城河、管理层）而非报告长度来评判
3. 在最终报告中标注每家公司的"信息充分度"（A/B/C级），让读者知道AI分析的可靠程度

## 第 3.5 步：⭐ 行业周期定位（库存周期 + 需求周期，强制）

> **完整方法论见 `skills/cycle-analysis.md`。**
> **周期行业的 PE 分母是假的**：周期顶部最典型的形态是"利润爆发 + PE 极低"。**行业研究的估值结论必须先过周期定位这一关。**
>
> **⭐ 但周期的定位是"时点判断 + 一票否决"，不是"选股标准"。** 周期好不能把一个平庸生意变成好投资；同理，周期差也不构成买入的理由。**周期只在已经通过第 2.5 步质量门槛的标的池里起作用。**

### 3.5.1 行业需求周期

| 观察维度 | 必取数据 | 判读 |
|---|---|---|
| 下游景气 | 装机量/出货量/渗透率/开工率（**具体数字 + 口径**） | 需求是在扩张还是见顶 |
| 价格与价差 | 产品价、原料价、毛利率；涨价收敛速度 | 需求拉动 / 成本传导 / 产能退出（后者脆弱） |
| 价格位置 | 板块距 52 周高点回撤、年初至今 | **高点日期是否集中在同一窄窗口**＝集体见顶 |
| 集体见顶判据 | 各成分股 52 周高点日期分布 | 高度集中＝板块级周期顶 |

### 3.5.2 行业库存周期（逐环节取数，分组中位数）

| 分组 | 家数 | 存货同比中位 | 存货−收入增速差 | TTM 周转天数（上年同期） | 合同负债同比 | 距 52 周高点 |
|---|---:|---:|---:|---:|---:|---:|

**必须逐家取数后取中位数，不得用个别公司代表全行业。** 同组公司要用同一口径、同一算法。

### 3.5.3 周期四象限（库存轴 × 订单轴）

| 象限 | 库存（周转天数） | 订单（合同负债） | 含义 | 默认动作 |
|---|---|---|---|---|
| Ⅰ 供不应求 | ↓ | ↑ | 需求真实 | 可买 |
| Ⅱ 订单未至 | ↓ | ↓ | 库存已消化、订单未至 | 观察仓 |
| Ⅲ 被动积压 | ↑ | ↓ | 货堆着卖不动 | 回避 |
| Ⅳ 主动补库 | ↑ | ↑ | 景气上行或周期顶备货 | 看价格拐点 |

### 3.5.4 行业周期定位结论（四档之一）

| 档位 | 判定依据 | 默认动作 |
|---|---|---|
| **周期底部** | 库存同比转负或周转天数低于上年同期 + 价格企稳 + 订单回升 | 可建仓 |
| **周期上行中段** | 需求仍上行 + 库存健康 + 估值未透支 | 持有/加仓 |
| **周期顶部** | 涨价收敛 + 利润/PE 背离（利润高、PE 低）+ 库存同比暴涨 | **不参与（不是做空）** |
| **周期下行中段** | 需求转负 + 库存未去化 + 股价已跌但 PE 仍高 | 等待 |

**每档必须给出：判定依据（带数字）+ 反面论据 + 可观测反转信号（指标 + 阈值）。**

## 第四步：各环节头部公司四大师分析

对每个产业链环节的**Tier 1和Tier 2公司**，执行以下分析（Tier 3/4公司简要点评即可）：

### 4.1 生意本质（段永平）
- 一句话定义这家公司在产业链中做什么
- 收入结构与增速
- 毛利率/净利率水平及趋势
- 现金流特征
- **追问**：这是一门好生意吗？为什么？

### 4.2 护城河（巴菲特）
用五类护城河评分（★1-5）：

| 护城河 | 强度 | 证据 |
|--------|------|------|
| 品牌/定价权 | | |
| 转换成本 | | |
| 网络效应 | | |
| 规模效应 | | |
| 技术/牌照壁垒 | | |

**追问**：10年后护城河还在吗？

### 4.3 风险（芒格）
- 这家公司最可能怎么失败？
- 最坏情景下值多少钱？
- 聪明人为什么不买？

### 4.4 管理层（段永平+巴菲特）
- CEO/创始人是谁？关键决策记录
- 持股比例与利益对齐
- 简评（A/B/C级）

### 4.5 估值快照
- **四个估值锚点**：PE(TTM归母) / PE(TTM扣非) / 正常化PE / 单季年化PE
- 与同环节竞争对手对比（仅作参照，不能代替自身历史分位）
- **与自身历史 PE 分位对比**：近3年分位 + 全历史分位（周期股用正常化利润重算）
- **⭐ 该公司的周期位置**：存货同比 / TTM 周转天数 vs 上年同期 / 四象限 / 周期档位
- 简评：显著低估/合理/明显高估（**必须先回答"这个利润是能力挣的还是价格给的"**）

### 4.6 推荐度（三层打分，质量层封顶）

**打分顺序固定：先打质量层 → 再打估值层 → 最后打周期层。后两层只能在上限内做减法，不能突破质量层给的天花板。**

#### 第一层：质量层 =（生意质量★ + 护城河★）÷ 2 —— 决定推荐度上限

| 质量层均分 | 推荐度上限 |
|---|---|
| ≥ 4.5 | ★★★★★ |
| 4.0 – 4.4 | ★★★★☆ |
| 3.0 – 3.9 | ★★★☆☆ |
| 2.0 – 2.9 | ★★☆☆☆ |
| < 2.0 | ★☆☆☆☆（不推荐，不论多便宜） |

#### 第二层：估值层 —— 在天花板内下调，最多 2 档

| 估值状态 | 判定条件 | 调整 |
|---|---|---|
| **显著低估** | ① 3 年分位<20% 且全历史分位<30%；② 扣非/归母≥85%；③ 扣非同比>0；④ 单季年化PE<扣非PE（四条同时满足） | 不下调 |
| **合理** | 以上都不满足 | 下调 1 档 |
| **明显高估** | ① 3 年分位>70% 或全历史分位>70%；或 ② 正常化PE>3×扣非PE；或 ③ 扣非PE>80倍且扣非增速<30% | 下调 2 档 |

**估值调整只能为 0、−1、−2，永远不能为正。**

#### 第三层：周期层 —— 一票否决，只能下调不能上调

| 周期档位 | 约束 |
|---|---|
| 周期底部 / 上行中段 | 不额外调整；也不能上调 |
| 周期顶部 | **不得高于 ★★★☆☆**；不新建仓（低 PE 在周期顶是最贵的估值） |
| 周期下行中段且库存未去化 | **不得高于 ★★★☆☆**，且不得进核心仓位 |

#### ⭐ 三条不能违反的规则

1. **估值便宜不能把推荐度打到质量层上限之上；周期好也不能。** 低估值与低库存只是"便宜"和"时点"，改变不了生意质量。
2. **质量层 ≥3.5（A2 及以上）的公司在明显高估时可以被下调到 ★★★☆☆ 观察**——但这是"**什么时候买**"的问题，不是"**要不要买**"的问题；两者在报告里必须分开表述。
3. **质量层 <3.5（A3）且通过 A 通道的，最多只能进期权仓位（≤5%），且必须显著低估 + 明确催化剂；B 通道一律 0 仓位，不得因为"便宜"进核心/卫星/期权仓位。**

★ 图例：
- ★★★★★ = 核心仓位候选（质量 + 估值 + 周期同时满足）
- ★★★★☆ = 卫星仓位候选
- ★★★☆☆ = 小仓 / 观察（**A1（4.0–4.4）合理 → 10–15%；A2（3.5–3.9）显著低估 → ≤10%；A3 显著低估+催化剂 → 期权 ≤5%**；其余一律 0%）
- ★★☆☆☆ = 不建仓（质量或安全边际不足，含期权）
- ★☆☆☆☆ = 不推荐

## 第七步：投资组合配置建议

### 7.1 推荐组合（质量门槛优先，估值与周期只调仓位）

**构建顺序：① 按质量层排序 → ② 剔除未过质量门槛的标的 → ③ 在剩余标的中按估值/周期决定仓位大小。**

| 层级 | 仓位占比 | **质量门槛（硬性）** | 标的 | 所属环节 | 核心逻辑 | 周期定位 | 推荐度 |
|------|---------|---------|------|---------|---------|---------|:---:|
| **核心仓位** | 占主题仓位 50–60% | 生意质量 ★★★★+ **且** 护城河 ★★★★+；质量层≥4.5；估值显著低估；周期不在顶部 | | | 最确定、护城河最宽 | | |
| **卫星仓位** | 占主题仓位 25–35% | 质量层≥4.5 且估值合理；或 4.0–4.4 且显著低估；周期不在顶部 | | | 弹性较大、确定性稍低 | | |
| **小仓 / 期权** | 占主题仓位 0–15% | **A1（4.0–4.4）合理→10–15%；A2（3.5–3.9）显著低估→≤10%；A3 显著低估+催化剂→期权≤5%**；其余一律 0% | | | 质量或安全边际有瑕疵，只给小仓 | | |
| **B 通道** | **0%** | 质量门槛未过 | — | — | **只观察，不进组合（含期权）** | — | — |
| **ETF替代** | 可替代以上全部 | — | | | 不想选股的"懒人方案" | — | — |

**⭐ 四条硬约束**：

1. **质量与安全边际的交换不能绕过。** 质量越好，要求的安全边际越低（A1 合理可小仓、≥4.5 合理可卫星）；质量越差，要求的安全边际越高（A2 只在显著低估时试探、A3 只在显著低估+催化剂时期权）。高估一律 0%，B 通道一律 0%。
2. **每只标的必须标注周期定位（周期底部/上行中段/顶部/下行中段）+ 库存三指标 + 推荐度**，且推荐度必须按 4.6 的三层打分算出，**不得手写**。
3. **核心仓位不得为空却被卫星仓位填满**——若没有标的通过核心仓位的质量门槛，就空着，把仓位让给 ETF 或现金，**不许拿卫星仓位凑数**。
4. **若行业整体质量层不达标，组合结论为"不配置"**，并写明"若一定要参与，只能以 ETF 小仓位试水"。此时即便行业在周期底部、估值极低，结论也不变——**估值便宜不构成买入理由，质量不够更是直接否定的理由**。

### 7.2 买入/卖出信号

**信号优先级：质量信号 > 周期信号 > 估值信号。质量信号出现即执行，不看估值和周期。**

| 信号类型 | 具体条件 |
|---------|---------|
| **质量恶化（最硬，最高优先级）** | **毛利率连续 2 个季度下滑且非一次性因素 / 经营现金流/净利润跌破 0.7 / 核心客户或渠道流失 / 护城河来源被证伪（如技术路线切换、专利到期、牌照放开）→ 直接降级或清仓，不等周期和估值** |
| 加仓信号 | 目标公司 TTM 存货周转天数同比下降 + 存货同比低于收入同比；或全行业 TTM 周转天数中位回到上年同期以下且价格企稳。**仅在 A 通道（质量层 ≥3.5）的标的上有效；B 通道不适用** |
| 减仓信号 | 库存同比继续跑赢收入增速、涨价涨幅收敛、利润与 PE 背离扩大 |
| 清仓信号 | 出现大额存货跌价准备计提 / 产品价格破位 / **质量层跌破 ★★★** |

**⭐ 反向纪律**：估值跌到历史极低分位、周期指标转好，**都不能作为加仓的理由**——它们只能作为"质量层已经达标"之后的加仓时点。

### 7.3 主题仓位上限建议
根据投资逻辑链的确定性和风险程度，建议该主题占总仓位的上限百分比。
