# 投资研究：巴菲特-芒格-段永平-李录 四大师综合分析框架

对 $ARGUMENTS 进行系统化投资研究分析。

## 研究框架

基于巴菲特、芒格、段永平、李录四位投资大师的方法论，按以下顺序执行：

- **第一段：是否值得跟踪**（因素①生意模式 + ②护城河 → 质量门槛）
- **第二段：什么时候买、买多少**（因素③周期 + ④估值 → 仓位）

> **唯一口径见 `skills/four-factor-framework.md`。** 本 skill 只写执行流程；四因素的定义、阈值、打分公式、否决线以该文件为准，不得另立一套。
>
> **顺序不能反**：生意模式与护城河先回答"值不值得跟踪"，周期与估值再回答"现在买不买、买多少"。周期先于估值，不等于周期先于生意模式。

### 前置步骤：AI研究偏见自觉（必须执行）

在开始研究前，先评估该公司的"AI可研究性"，识别潜在的数据偏见：

**信息丰富度评级**：
| 等级 | 特征 | AI研究陷阱 | 应对策略 |
|------|------|-----------|---------|
| A级（信息充裕） | 上市多年、券商覆盖多、媒体报道密集 | 共识过强，AI输出趋同于市场定价，alpha有限 | 重点做反面检验：聪明人为什么不买？被忽略的风险是什么？ |
| B级（信息适中） | 上市1-3年、覆盖有限、部分数据需推算 | AI可能用"合理推测"填补空白，看起来完整实则虚假确定性 | 每个推算数据标注置信度，区分"有据推算"和"凭空填充" |
| C级（信息稀缺） | 刚上市/冷门股/新兴市场、几乎无覆盖 | AI会因资料不足而过度保守，误判为"看不清=不好" | 用第一性原理提问（见下方），从有限信息中提取商业本质 |

**C级公司的第一性原理研究法**：
当公开资料不足时，不要试图拼凑出"看起来完整"的报告，而是聚焦以下底层问题：
1. 客户是谁？为什么付钱？有没有替代选择？
2. 复购靠什么驱动？是习惯、锁定、还是持续创造新价值？
3. 竞争对手拿100亿能复制这门生意吗？
4. 管理层做过什么关键决策？这些决策反映了什么判断力和价值观？

**偏见自查清单**（研究全程保持警惕）：
- [ ] 我的"确定性"感受是来自生意本质，还是来自资料数量？
- [ ] 如果把这家公司的资料量减少一半，我的结论会变吗？
- [ ] AI输出的分析是否与市场共识高度雷同？如果是，我的信息优势在哪？
- [ ] 是否存在"公开资料很少但生意本质极好"的可能性被低估了？

将信息丰富度评级结果写入报告开头，并在最终结论中注明"AI研究置信度"与"实际投资确定性"的区别。

### 第一步：数据收集

> **数据源规范**：参见 `skills/financial-data.md`。所有财务数据必须来自两个独立来源，误差>1%须标记。
> - 美股：macrotrends（主）+ stockanalysis（副）
> - 港股：aastocks（主）+ macrotrends ADR（副）
> - A股：东方财富（主）+ 巨潮资讯（副）

使用 Task 工具启动后台 Agent，从网络收集以下数据：

1. 收入结构：最近财年及近4季度分部收入、增速、毛利率
2. 财务指标：近5年收入、净利润、毛利率、经营利润率、自由现金流、现金储备
3. 竞争格局：市场份额、主要竞争对手对比
4. 商业模式与护城河：核心竞争优势来源
5. 技术能力：核心技术栈、研发投入
6. 管理层：创始人/CEO履历、持股比例、关键决策记录
7. 行业前景：TAM（总可寻址市场）、增长预测
8. 风险因素：地缘政治、监管、供应链等
9. 当前估值：市值、PE、PS、PEG、EV/Revenue
10. 多空双方核心论点
11. **周期数据（强制）**：近 8 个季度的期末存货、营业成本、合同负债（用于算 TTM 存货周转天数、存货−收入增速差、单季差分）；行业产品价/原料价/下游出货量序列
12. **质量门槛数据（强制）**：近10年逐年ROE、近5年经营现金流与资本开支、最新年度EBIT与利息支出、近10年毛利率/净利率、5年经济稀释（累计"吸收投资收到的现金"÷期末归母净资产）

#### 数据交叉验证（必须执行，使用金融严谨性工具）

数据收集完成后，**必须调用 `tools/financial_rigor.py` 对关键数据进行程序化验证**，杜绝LLM心算误差。

**必须验证的数据点**：
- 总股本（从交易所、Yahoo Finance、StockAnalysis 等至少2个源确认）
- 当前股价和市值（**手动计算 股价×总股本 并与报告市值对比，防止单位错误**）
- 最近财年收入和净利润（从公司年报+至少1个第三方源确认）
- 现金储备和净现金（现金+短期投资-总债务，注意口径差异）
- 管理层持股比例（区分经济权益和投票权，注意AB股结构）

**强制验证步骤（使用Bash调用工具）**：

Step 1 — 市值验算（精确十进制，非浮点）：
```bash
python3 tools/financial_rigor.py verify-market-cap \
  --price {股价} --shares {总股本} --reported {报告市值} --currency {币种}
```

Step 2 — 关键数据多源交叉验证：
```bash
python3 tools/financial_rigor.py cross-validate \
  --field {字段名} --values '{"来源1": 数值, "来源2": 数值}' --unit {单位}
```
对收入、净利润、现金储备分别执行。

Step 3 — 估值指标精确验算（PE/PB/ROE/FCF Yield 等）：
```bash
python3 tools/financial_rigor.py verify-valuation \
  --price {股价} --eps {EPS} --bvps {每股净资产} --fcf-per-share {每股FCF} --dividend {每股股息}
```

**验证规则**：
1. 每个关键数据点至少2个独立来源
2. 发现来源间有差异时，优先采用公司年报/交易所数据，并注明差异原因
3. **所有涉及计算的数据必须通过工具验算，禁止LLM心算**
4. 工具输出结果直接嵌入报告附录"关键数据交叉验证记录"
5. 如果工具报告 ❌ 偏差过大，必须排查原因后才能继续分析

**常见错误防范**：
- 市值单位：港币亿 vs 人民币亿 vs 美元亿，容易漏写/多写一个零
- FCF口径：不同来源对资本支出的定义可能不同（是否含租赁、收购等）
- 债务口径：是否包含经营租赁负债
- 持股比例：AB股公司的经济权益 ≠ 投票权

### 第二步：生意模式与生意质量 — 段永平"对的生意"

> 这是因素①，回答"值不值得跟踪"的一半。**本步不看估值、不看周期。**

分析要点：
- 用一句话定义这门生意的本质
- 收入结构拆解（图表）
- 5年盈利能力趋势（图表）
- 商业模式画布：一次性销售 vs 订阅/复购？硬件 vs 软件 vs 平台？
- 生态粘性/客户锁定强度
- 毛利率水平与同行对比，解释为什么高/低
- 经营杠杆分析
- **质量数据（必须列）**：10年平均ROE、5年累计自由现金流、5年平均经营现金流/净利润、10年平均毛利率/净利率、资本开支/收入、5年经济稀释
- **定价权来源**：品牌、转换成本、网络效应、成本/规模优势。**说不出来源的，就是没有定价权。**
- **生意质量★**：按 `skills/four-factor-framework.md` 第一节的评分标准打分，附数据与证据

**段永平式追问**：这门生意好在哪？如果只能用一句话描述，是什么？

### 第三步：护城河评估 — 巴菲特"经济护城河"

> 这是因素②，回答"值不值得跟踪"的另一半。

逐一验证五类护城河：

| 护城河类型 | 验证方法 | 强度★ | 具体证据 |
|-----------|---------|:---:|---------|
| 品牌/定价权 | 是否能在不损失销量的情况下提价？ | | |
| 转换成本 | 客户迁移到竞品的成本有多高？ | | |
| 网络效应 | 用户越多产品越好吗？ | | |
| 规模效应 | 规模带来的成本优势有多大？ | | |
| 技术/专利壁垒 | 技术领先几年？能否被复制？ | | |

**综合分取法**：护城河★ = 五类中最高的单类得分，不取平均。报告必须写清：是哪一类、证据是什么、10年后还在不在。

分析护城河趋势：过去5年变宽还是变窄？未来5年预判。

**巴菲特式追问**：10年后这条护城河还在吗？什么能摧毁它？

### 第四步：行业与文明趋势 — 李录"文明演进框架"

- 判断所在行业是否处于"文明级范式转移"
- 历史技术革命类比（蒸汽机/电力/互联网/AI）
- TAM增长曲线与天花板分析
- 公司在产业价值链中的位置
- 技术路线风险
- 客户/供应商集中度分析

**李录式追问**：站在20年后回看，这家公司是"这个时代的标准石油"还是"昙花一现的3Com"？

### 第五步：逆向思考与风险清单 — 芒格"反过来想"

- 列出"这家公司可能失败的所有路径"（表格：路径/概率/影响程度）
- 历史类比：找到历史上处于相似位置的公司，结局如何？
- 跨学科分析：用网络效应理论、技术采纳曲线、竞争博弈等模型交叉验证
- 偏误自查：叙事偏差、锚定效应、幸存者偏差
- 收集空方核心论点

**芒格式追问**：我最可能在哪里犯错？聪明人为什么会不买/做空这家公司？

### 第六步：管理层评估 — 段永平"对的人" + 巴菲特"管理层诚信"

- CEO/创始人关键决策复盘（表格：时间/决策/结果/评分）
- 资本配置能力：研发回报率、并购成功率、回购时机
- 股东利益一致性：管理层持股、薪酬结构、减持记录
- 组织能力：团队稳定性、关键人才风险
- 企业文化特征

**段永平式追问**：如果CEO退休，这家公司还能保持竞争力吗？

### 第七步：质量门槛与"是否值得跟踪"判定（强制闸门）

> **这一步是四因素框架的闸门。通过 → A 通道，进入周期+估值；不通过 → B 通道，不做估值、不进组合。**
> 工具：`skills/quality-screen.md`。不得用估值或周期影响本步结论。

#### 7.1 六条淘汰指标 + 一条观察指标

| # | 指标 | 淘汰线 | 本案例数值 | 通过? |
|---|------|-------|---|:---:|
| ① | 10年平均ROE | < 8% | | |
| ② | 5年累计自由现金流 | < 0 | | |
| ③ | 利息覆盖倍数（EBIT/利息） | < 2倍 | | |
| ④ | 长期毛利率 | < 15% | | |
| ⑤ | 经营现金流 / 净利润（5年均值） | < 0.7 | | |
| ⑥ | 长期净利率 | < 5% | | |
| ⑦ | 5年经济稀释 | > 20% 仅观察，不淘汰 | | 观察项 |

**豁免规则**：
- **A（战略投入期）**：上市不足10年 + 毛利率>30% + 最近2年经营现金流为正 → 豁免①。
- **B（主动低利润率）**：当前毛利率>30% + 当前净利率>5% → 豁免④⑥。
- **C（高周转薄利）**：ROE>20% + 经营现金流/净利润>1.0 + 会员/平台/高周转模式 → 豁免④⑥。

#### 7.2 A/B 通道

| 通道 | 条件 | 处理 |
|---|---|---|
| **A 通道（值得跟踪）** | 6条淘汰指标全过（含豁免）**且**至少1类护城河≥★★★ | 进入周期+估值；按质量层分 A1/A2/A3 |
| **A1** | 质量层≥4.0（**不再要求生意质量与护城河各自≥4★**；护城河下限仍为 A 通道的 ★★★） | ≥4.5 显著低估→核心；≥4.5 合理→卫星；4.0–4.4 显著低估→卫星；4.0–4.4 合理→小仓 10–15%；高估→0 |
| **A2** | 质量层 3.5–3.9 | **可建试探仓（≤10% 主题仓位）**：仅当显著低估（估值调整 0）且周期不在顶部/下行未去化；合理及以上一律 0% |
| **A3** | 质量层 <3.5 | 只观察；**显著低估 + 明确催化剂**时最多期权仓位 ≤5%；合理及以上一律 0% |
| **B 通道（不值得跟踪）** | 任一淘汰指标不过且无法豁免，**或**五类护城河全部<★★★ | **不做估值、不进组合（含期权）**；只记录"为什么便宜" |

#### 7.3 质量层与推荐度上限

> **质量层 =（生意质量★ + 护城河★）÷ 2**

| 质量层 | 推荐度上限 |
|---|---|
| ≥4.5 | ★★★★★ |
| 4.0–4.4 | ★★★★☆ |
| 3.0–3.9 | ★★★☆☆ |
| 2.0–2.9 | ★★☆☆☆ |
| <2.0 | ★☆☆☆☆（不推荐，不论多便宜） |

#### 7.4 被排除的便宜货（有同业对比时必列）

| 公司 | 代码 | PE(TTM) | 扣非PE / 正常化PE | 门槛失败项 | 排除理由 | 若强行买入最可能亏在哪 |
|---|---|---|---:|---:|---|---|

单公司研究没有同业对比时，至少写一段"低 PE 陷阱检查"：当前估值是否由周期顶部利润、非经常性收益或 Level-3 浮盈造成。

#### 7.5 本步输出

> **是否值得跟踪：A/B 通道 + 质量层 + 推荐度上限。**
> 这个结论只由因素①和②决定；估值便宜、周期在底部都不能改变它。

### 第八步：周期定位（库存周期 + 需求周期，强制）

> **前置条件：第七步判定为 A 通道。** B 通道不做周期分析，因为不进组合。
> **完整方法论见 `skills/cycle-analysis.md`。**
> **周期股的 PE 分母是假的**：周期顶部最典型的形态是"利润爆发 + PE 极低"。**本模块必须在估值模块之前完成，并直接决定"什么时候买、买多少"。**
> **周期只回答时点判断 + 一票否决，不回答是否值得跟踪；不能上调推荐度。**

#### 8.1 库存周期（从报表直接算）

| 指标 | 公式 | 口径要求 |
|---|---|---|
| 存货同比 | 期末存货 ÷ 上年同期期末存货 − 1 | 同一报表日、同一口径 |
| **存货−收入增速差** | 存货同比 − 同期收入同比 | **>0 = 累库；<0 = 去库/供不应求** |
| TTM 存货周转天数 | （期初存货+期末存货）÷2 ÷ TTM 营业成本 × 365 | **必须 TTM**，上年同期用同一算法重算 |
| 单季存货增量 | 本期末存货 − 上期末存货 | 区分渐进备货与突然压货 |
| 存货 ÷ 市值、存货 ÷ TTM 收入 | >30% 即为大赌注 | 价格回落时减值吞掉一年利润 |

**存货结构（必查附注）**：期末 vs 期初逐项对比原材料/在产品/库存商品/合同履约成本——
增量集中在**原材料/在产品** = 主动备货；集中在**库存商品** = 被动滞销；**跌价准备计提额 ≪ 存货增量或准备率下降** = 减值被推迟。

**订单代理**：合同负债同比/较年初（⚠️ 小盘设计公司绝对值 <0.2 亿时百分比失真，以存货为主）；制造业可辅以预付款项、应付票据、前五大客户/供应商集中度。

#### 8.2 需求周期

- **单季序列（至少 6 个单季，必须差分实算）**：收入、毛利率、归母净利率、单季经营现金流、存货。**累计数会掩盖崩塌。**
- **价格与价差**：产品价、原料价、毛利率；涨价性质要区分**需求拉动 / 成本传导 / 产能退出**（后者脆弱）。
- **下游景气**：具体数字与口径（装机量、出货量、渗透率、开工率、产能利用率）。
- **价格位置**：距 52 周高点回撤、年初至今；**板块高点日期是否集中在同一窄窗口**（集体见顶判据）。

#### 8.3 周期四象限（库存轴 × 订单轴）

| 象限 | 库存（周转天数） | 订单（合同负债） | 含义 | 默认动作 |
|---|---|---|---|---|
| Ⅰ 供不应求 | ↓ | ↑ | 需求真实 | 可买 |
| Ⅱ 订单未至 | ↓ | ↓ | 库存已消化、订单未至 | 观察仓 |
| Ⅲ 被动积压 | ↑ | ↓ | 货堆着卖不动 | 回避 |
| Ⅳ 主动补库 | ↑ | ↑ | 景气上行或周期顶备货 | 看价格拐点 |

#### 8.4 周期定位结论（四档之一，必须明确）

| 档位 | 判定依据 | 默认动作 |
|---|---|---|
| **周期底部** | 库存同比转负或周转天数低于上年同期 + 价格企稳 + 订单回升 | 可建仓 |
| **周期上行中段** | 需求仍上行 + 库存健康 + 估值未透支 | 持有/加仓 |
| **周期顶部** | 涨价收敛 + 利润/PE 背离 + 库存同比暴涨 | **不参与（不是做空）** |
| **周期下行中段** | 需求转负 + 库存未去化 + 股价已跌但 PE 仍高 | 等待 |

**每档必须给出：① 判定依据（带数字）② 反面论据 ③ 可观测的周期反转信号（指标 + 阈值）。**

**⭐ 三条防陷阱纪律**：① "库存低"不等于买点（常由需求塌陷造成，须配合同单负债交叉验证）；② 低 PE 在周期顶是最贵的估值；③ 归母同比中位数必须剔除扭亏与亏损公司（两期归母任一 ≤0 时百分比变化无经济含义）。

### 第九步：估值与安全边际 — 巴菲特"内在价值" + 段永平"对的价格"

> **前置条件：第八步周期定位必须已完成。** 低 PE 在周期顶部是最贵的估值；本步骤的每个 PE 都要标注"这个利润是能力挣的还是价格给的"。
> **估值只决定什么时候买、买多少，不决定是否值得跟踪；估值调整只能下调，不能上调。**

#### 9.1 四个估值锚点

| 锚点 | 算法 | 回答的问题 |
|---|---|---|
| PE(TTM归母) | 市值 ÷ 最近四个季度归母净利润 | 市场最常用的表观估值 |
| **PE(TTM扣非)** | 市值 ÷ 最近四个季度扣非归母净利润 | 剔除一次性收益后的真实经营估值 |
| **正常化PE** | 市值 ÷ 穿越一轮周期的常态利润（至少3年归母均值；周期股用完整周期均值） | 周期顶/底的真实估值 |
| **单季年化PE** | 市值 ÷（最近单季归母 × 4） | 当前盈利能力若延续的估值 |

**四个锚点分歧越大，利润的"一次性/周期性"越强。** 分歧 >3 倍时，以正常化 PE 为主锚点。存在公允价值变动、Level-3 浮盈、BD 首付款、一次性退款等情形时，必须同时列示表观 PE 与扣非 PE。

#### 9.2 历史分位

- 用**自建 PE(TTM) 序列**，同时给**近3年分位**与**全历史分位**。
- **两个口径同时低才是真低**；两者矛盾时取更保守的。不得用同行绝对值代替自身历史分位。
- 周期股用正常化利润重算分位；不得用周期顶部利润算出的低分位直接称"便宜"。

#### 9.3 估值状态与调整

| 估值状态 | 判定条件 | 调整 |
|---|---|---|
| **显著低估** | ① 3年分位<20% 且全历史分位<30%；② 扣非/归母≥85%；③ 扣非同比>0；④ 单季年化PE<扣非PE（四条同时满足） | 0 |
| **合理** | 以上都不满足 | −1 |
| **明显高估** | ① 3年分位>70% 或全历史分位>70%；或 ② 正常化PE>3×扣非PE；或 ③ 扣非PE>80倍且扣非增速<30% | −2 |

**估值调整只能为 0、−1、−2，永远不能为正。** 无单季数据时，④ 用 TTM 替代并注明。

#### 9.4 三情景估值（必须通过工具精确计算，禁止心算）

```bash
python3 tools/financial_rigor.py three-scenario \
  --price {股价} --eps {EPS} --shares {总股本亿} \
  --growth {乐观增速} {中性增速} {悲观增速} \
  --pe {乐观PE} {中性PE} {悲观PE} --years 3 --currency {币种}
```

- 三情景必须写清业务假设；价格区间是纪律，不是预测。
- 报告必须给出：买入区间、观察区间、合理区间、高估区间；以及首批/加仓触发价。
- 与自身历史估值对比；与同行估值对比（同行对比只作参照，不代替自身历史分位）。

#### 9.5 仓位映射

> **质量与安全边际是交换关系**：质量越好，要求的安全边际越低；质量越差，要求的安全边际越高；但任何质量都不允许在明显高估时建仓。仓位由「质量层 × 估值状态」共同决定，星级只是汇总。

| 质量层 \ 估值状态 | 显著低估（调整 0） | 合理（调整 −1） | 明显高估（调整 −2） |
|---|---|---|---|
| **≥4.5（A1）** | **核心 50–60%**（周期允许） | 卫星 25–35% | 0% |
| **4.0–4.4（A1）** | 卫星 25–35% | **小仓 10–15%** | 0% |
| **3.5–3.9（A2）** | **试探仓 ≤10%** | 0% | 0% |
| **<3.5（A3）** | 期权 ≤5%（须有明确催化剂） | 0% | 0% |
| **<2.0** | 0% | 0% | 0% |

| 最终星级 | 仓位层级 | 占主题仓位 | 备注 |
|---|---|---|---|
| ★★★★★ | 核心仓位 | 50–60% | 质量层≥4.5 + 显著低估 + 周期允许 |
| ★★★★☆ | 卫星仓位 | 25–35% | 质量层≥4.5 合理；或 4.0–4.4 显著低估 |
| ★★★☆☆ | 小仓 / 观察 | 0–15% | **仅三种情形**：A1（4.0–4.4）合理 → 10–15%；A2（3.5–3.9）显著低估 → ≤10%；A3 显著低估+催化剂 → 期权 ≤5%。其余 0% |
| ★★☆☆☆ | 不建仓 | 0% | 质量或安全边际不足（含期权） |
| ★☆☆☆☆ | 不推荐 | 0% | — |
| B 通道 | 0% | 0% | 不做估值、不进组合（含期权） |

> **周期顶部、周期下行中段且库存未去化 → 一律不新建仓**，即便最终落到 ★★★。

**段永平式追问**：如果股市明天关闭5年，你愿意以这个价格持有吗？

2. 使用 Markdown 表格呈现关键数据
3. 每个模块末尾必须有对应大师的"追问"
4. 最终将完整报告写入 `~/[公司名]投资研究报告.md`
5. 结论要明确，不回避给出买入/观望/回避的建议
6. 估值部分必须给出具体的价格区间
7. **报告开头**必须包含"信息丰富度评级"（A/B/C）和"AI研究局限性声明"
8. **报告结尾**必须区分"AI分析置信度"与"投资确定性"——前者取决于资料量，后者取决于生意本质。明确告知读者：本报告的哪些结论基于充分数据，哪些基于有限信息的推理
9. **报告必须包含"质量门槛"独立章节**（第七步）：6条淘汰指标 + 1条观察指标 + 豁免规则 + A/B通道 + 质量层 + 推荐度上限。**未通过质量门槛的 B 通道公司，不做估值、不进组合。**

## 数据抽检（准出流程）

报告写入文件后，**必须**执行数据抽检，通过后方可发布：

**Step 1 — 提取抽检清单（15%随机抽样）：**
```bash
python3 tools/report_audit.py extract \
  --report <报告文件路径>
```
输出 JSON 模板，每项含 `fetched_value`（待填）。

**Step 2 — 取数核验：**
对清单中每个数据点，按 `skills/financial-data.md` 规范从可靠信源取数
（美股：macrotrends+stockanalysis；港股：aastocks+macrotrends；A股：东方财富+巨潮资讯），
填入 `fetched_value` / `fetched_source` / `fetched_value2` / `fetched_source2`。

**Step 3 — 输出判决：**
```bash
python3 tools/report_audit.py verdict \
  --results '<填好的JSON>' \
  --report <报告文件名>
```

- **【准出】**：所有抽检点偏差 ≤ 1% → 报告可发布
- **【打回】**：任意点偏差 > 1% → 修正对应数据后重新抽检，直到准出
