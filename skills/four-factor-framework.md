# 四因素投资框架：生意模式 / 护城河 / 周期 / 估值

> **本模块是行业研究、公司研究、团队研究、漏斗筛选、买入 Checklist 的唯一口径。**
> 其他 skill 不得另写一套阈值、打分或否决线；只能引用本模块。

## 零、一句话分工

**生意模式 + 护城河 = 是否值得跟踪（入池资格）；周期 + 估值 = 什么时候买、买多少（时点与仓位）。**

| 因素 | 回答的问题 | 判定时点 | 判定工具 | 不通过的处理 | 能否上调推荐度 |
|---|---|---|---|---|---|
| ① 生意模式 / 生意质量 | 这门生意赚不赚钱、赚的是不是现金、资本回报高不高、有没有定价权 | **跟踪前** | `skills/quality-screen.md` 6 条淘汰指标 + 1 条观察指标 + 生意质量★1–5 | 直接排除（B 通道），不进入周期/估值 | 是（质量层决定上限） |
| ② 护城河 | 十年后这门生意还属不属于它 | **跟踪前** | 五类护城河★1–5，取最强一类为综合分 | 五类全部 <★★★ → B 通道；核心仓位需 ★★★★ | 是 |
| ③ 周期 | 现在处在周期哪一段 | **买入前**（质量门槛之后） | `skills/cycle-analysis.md` 三指标 + 四象限 + 四档 | 周期顶 → 不建仓、封顶★★★；下行中段且库存未去化 → 封顶★★★且不进核心 | **否，只能下调/封顶** |
| ④ 估值 | 现在买要付多少钱 | **买入前**（周期之后） | 四锚点 + 自身历史分位 + 三情景 | 高估 → 下调 1–2 档；低估 → 不下调，也不上调 | **否，只能下调** |

**决策顺序固定**：① → ② → 质量门槛（是否值得跟踪）→ ③ → ④（什么时候买、买多少）→ 推荐度合成。

数据收集阶段可以并行取周期数据，但**报告结论的顺序不能反**。周期先于估值，不等于周期先于生意模式。

### 两条铁律

1. **估值便宜 + 生意质量一般 = 不会有非常好的结果。** 低估值不能把平庸生意变成好投资；便宜通常有原因（资本回报衰减、无定价权、纸面利润、生意收缩）。
2. **周期只做时点判断 + 一票否决，不做选股标准。** 周期好不能把平庸生意变成好投资；周期差也不构成买入理由。

## 一、因素①：生意模式与生意质量

### 1.1 要回答的问题

- 一句话说清：卖什么、卖给谁、怎么收钱。
- 收入结构、增速、毛利率/净利率水平与趋势。
- 10 年平均 ROE、5 年累计自由现金流、5 年平均经营现金流/净利润。
- 资本开支强度、负债水平。
- **定价权来源**：品牌、转换成本、网络效应、成本/规模优势。**说不出来源的，就是没有定价权。**

### 1.2 硬指标

统一使用 `skills/quality-screen.md`：

- **6 条淘汰指标**：10 年平均 ROE <8%；5 年累计 FCF <0；利息覆盖倍数 <2；长期毛利率 <15%；5 年平均 OCF/净利润 <0.7；长期净利率 <5%。
- **1 条观察指标**：5 年经济稀释 >20%——只标注、不淘汰，估值时用稀释后 EPS 做敏感性。
- **3 条豁免**：A 战略投入期；B 主动低利润率；C 高周转薄利。

### 1.3 生意质量★ 评分标准

| 星级 | 条件 |
|---|---|
| ★★★★★ | 6 条淘汰指标全过，且 ROE≥20%、毛利率≥40%、OCF/净利润≥1.0、资本开支/收入≤5%、有清晰定价权来源 |
| ★★★★☆ | 6 条全过，且至少 3 项优秀（ROE≥15%、毛利率≥30%、OCF/净利润≥0.8、净利率≥10%、资本开支/收入≤10%） |
| ★★★☆☆ | 6 条全过，但多数指标平庸；或 1 条靠豁免通过 |
| ★★☆☆☆ | 1–2 条未过且只能部分豁免；或趋势明显恶化 |
| ★☆☆☆☆ | 多条未过、无法豁免；或 FCF 持续为负 |

**评分必须附数据与来源。** 估计值标注"估计"。

## 二、因素②：护城河

### 2.1 五类护城河

| 护城河类型 | 验证问题 |
|---|---|
| 品牌 / 定价权 | 能否在不损失销量的情况下提价？ |
| 转换成本 | 客户迁移到竞品的成本有多高？ |
| 网络效应 | 用户越多产品越好吗？ |
| 规模效应 | 规模带来的成本优势有多大？ |
| 技术 / 牌照 / 资源壁垒 | 技术领先几年？能否被复制？ |

### 2.2 护城河★ 评分标准

| 星级 | 条件 |
|---|---|
| ★★★★★ | 2 类以上强护城河叠加，且过去 5 年变宽 |
| ★★★★☆ | 至少 1 类强护城河，10 年内难以复制，趋势稳定或变宽 |
| ★★★☆☆ | 有护城河但不够深，或趋势不明 |
| ★★☆☆☆ | 护城河正在被侵蚀 |
| ★☆☆☆☆ | 无明显护城河 |

### 2.3 综合分取法

> **护城河★ = 五类中最高的单类得分，不取平均。**

理由：一条足够宽的护城河可以独立支撑生意；把五类平均会把"只有一条深沟"的好公司误杀。报告必须写清：**是哪一类、证据是什么、10 年后还在不在。**

### 2.4 门槛

| 用途 | 门槛 |
|---|---|
| **是否值得跟踪** | 至少 1 类 ≥★★★ |
| **核心仓位** | 综合护城河 ★★★★ 及以上 |

## 三、质量门槛：是否值得跟踪

### 3.1 A / B 通道

| 通道 | 条件 | 处理 |
|---|---|---|
| **A 通道（值得跟踪）** | 6 条淘汰指标全过（含豁免）**且**至少 1 类护城河 ≥★★★ | 进入周期 + 估值；按质量层分 A1/A2/A3 |
| **B 通道（不值得跟踪）** | 任一淘汰指标不过且无法豁免，**或**五类护城河全部 <★★★ | **不做估值、不进组合**；只记录"为什么便宜" |

### 3.2 质量层与推荐度上限

> **质量层 =（生意质量★ + 护城河★）÷ 2**

| 质量层 | 推荐度上限 |
|---|---|
| ≥4.5 | ★★★★★ |
| 4.0–4.4 | ★★★★☆ |
| 3.0–3.9 | ★★★☆☆ |
| 2.0–2.9 | ★★☆☆☆ |
| <2.0 | ★☆☆☆☆（不推荐，不论多便宜） |

### 3.3 A 通道内部细分

| 层级 | 条件 | 可竞争仓位（最终仍由三层打分决定） |
|---|---|---|
| **A1** | 质量层 ≥4.0，且生意质量≥4★、护城河≥4★ | 核心 / 卫星：质量层 ≥4.5 且估值调整 0 → 可竞争核心；4.0–4.4 → 最高卫星 |
| **A2** | 质量层 3.5–3.9 | **只观察（0 仓位）**：推荐度上限为 ★★★，达不到卫星的 ★★★★ |
| **A3** | 质量层 <3.5 | 只观察；有明确催化剂且最终星级 ≥★★ 时最多期权仓位 |

### 3.4 核心仓位的条件

- **必要条件**：生意质量★★★★+ **且** 护城河★★★★+。
- **充分条件**：质量层 ≥4.5 + **估值调整 0（显著低估）** + 周期不在顶部/下行未去化。质量层 ≥4.5 但估值调整 −1 时，最终为 ★★★★☆（卫星），不进核心。
- 最终以第六章三层打分为准；必要条件不等于自动进核心。

### 3.5 被排除的便宜货（强制表）

行业研究、漏斗筛选、多公司对比必须单列：

| 公司 | 代码 | PE(TTM) | 扣非PE / 正常化PE | 门槛失败项 | 排除理由 | 若强行买入最可能亏在哪 |
|---|---|---|---:|---:|---|---|

单公司研究若与同业对比或出现"低 PE 替代标的"，也必须列这张表；没有同业对比时，至少写一段"低 PE 陷阱检查"。

**这张表的作用是防止用低估值凑组合。不写这张表，等于没有执行质量门槛。**

### 3.6 报告必须回答

> **这家公司/这个行业值得跟踪吗？**（A/B 通道 + 质量层 + 推荐度上限）

这个结论**只能由因素①和②决定**。估值便宜、周期在底部，都不能改变"是否值得跟踪"的答案。

## 四、因素③：周期

### 4.1 角色

- 只回答：**现在处在周期哪一段 → 什么时候买、买多少。**
- **只对 A 通道标的生效。** B 通道不做周期分析，因为不进组合。
- **一票否决，不能上调推荐度。** 周期好不是买入理由，周期差可以是回避理由。

### 4.2 必算指标

完整方法论见 `skills/cycle-analysis.md`。至少包括：

| 指标 | 公式 | 口径要求 |
|---|---|---|
| 存货同比 | 期末存货 ÷ 上年同期期末存货 − 1 | 同一报表日、同一口径 |
| **存货−收入增速差** | 存货同比 − 同期收入同比 | >0 = 累库；<0 = 去库/供不应求 |
| TTM 存货周转天数 |（期初+期末）÷2 ÷ TTM 营业成本 ×365 | 必须 TTM；上年同期用同一算法重算 |
| 单季存货增量 | 本期末存货 − 上期末存货 | 区分渐进备货与突然压货 |
| 存货结构 | 原材料/在产品/库存商品/合同履约成本 | 增量在原材料/在产品 = 主动备货；在库存商品 = 被动滞销 |
| 订单代理 | 合同负债同比/较年初 | 小盘公司绝对值 <0.2 亿时百分比失真，以存货为主 |
| 单季序列 | ≥6 个单季收入、毛利率、归母净利率、经营现金流 | **必须差分实算，累计数会掩盖崩塌** |

### 4.3 周期四象限（库存轴 × 订单轴）

| 象限 | 库存（周转天数） | 订单（合同负债） | 含义 | 默认动作 |
|---|---|---|---|---|
| Ⅰ 供不应求 | ↓ | ↑ | 需求真实 | 可买 |
| Ⅱ 订单未至 | ↓ | ↓ | 库存已消化、订单未至 | 观察仓 |
| Ⅲ 被动积压 | ↑ | ↓ | 货堆着卖不动 | 回避 |
| Ⅳ 主动补库 | ↑ | ↑ | 景气上行或周期顶备货 | 看价格拐点 |

### 4.4 周期四档结论

| 档位 | 判定依据（至少两条） | 默认动作 |
|---|---|---|
| **周期底部** | 库存同比转负或周转天数低于上年同期 + 价格企稳 + 订单回升 | 可建仓 |
| **周期上行中段** | 需求仍上行 + 库存健康 + 估值未透支 | 持有/加仓 |
| **周期顶部** | 涨价收敛 + 利润/PE 背离（利润高、PE 低）+ 库存同比暴涨 | **不参与（不是做空）** |
| **周期下行中段** | 需求转负 + 库存未去化 + 股价已跌但 PE 仍高 | 等待 |

**每一档必须给出：① 判定依据（带数字）② 反面论据 ③ 可观测的反转信号（指标 + 阈值）。**

### 4.5 周期封顶规则

| 档位 | 约束 |
|---|---|
| 周期底部 / 上行中段 | 不额外调整；但也不能上调 |
| **周期顶部** | **不得高于 ★★★☆☆**；不新建仓 |
| **周期下行中段且库存未去化** | **不得高于 ★★★☆☆**；不得进核心仓位 |

### 4.6 三条防陷阱纪律

1. **"库存低"不等于买点。** 常由需求塌陷造成，必须配合同单负债/收入增速交叉验证。
2. **低 PE 在周期顶是最贵的估值。** 先定周期位置，再谈估值；任何低估值结论都要先回答"这个利润是能力挣的还是价格给的"。
3. **单季必须差分实算；存货结构优先于存货总量。** 归母同比中位数必须剔除扭亏与亏损公司。

## 五、因素④：估值

### 5.1 角色

- 只回答：**现在买要付多少钱 → 买多少、什么价格买。**
- **不能决定是否值得跟踪**；不能上调推荐度。
- 必须先完成周期定位，再谈估值。

### 5.2 四个估值锚点

| 锚点 | 算法 | 回答的问题 |
|---|---|---|
| PE(TTM归母) | 市值 ÷ 最近四个季度归母净利润 | 市场最常用的表观估值 |
| **PE(TTM扣非)** | 市值 ÷ 最近四个季度扣非归母净利润 | 剔除一次性收益后的真实经营估值 |
| **正常化PE** | 市值 ÷ 穿越一轮周期的常态利润（至少 3 年归母均值；周期股用完整周期均值） | 周期顶/底的真实估值 |
| **单季年化PE** | 市值 ÷（最近单季归母 × 4） | 当前盈利能力若延续的估值 |

**四个锚点分歧越大，利润的"一次性/周期性"越强。** 分歧 >3 倍时，以正常化 PE 为主锚点。存在公允价值变动、Level-3 浮盈、BD 首付款、一次性退款等情形时，必须同时列示表观 PE 与扣非 PE。

### 5.3 历史分位

- 用**自建 PE(TTM) 序列**，同时给**近 3 年分位**与**全历史分位**。
- **两个口径同时低才是真低**；两者矛盾时取更保守的。不得用同行绝对值代替自身历史分位。
- 周期股用正常化利润重算分位；不得用周期顶部利润算出的低分位直接称"便宜"。

### 5.4 估值状态与调整

| 估值状态 | 判定条件 | 调整 |
|---|---|---|
| **显著低估** | ① 3 年分位 <20% 且全历史分位 <30%；② 扣非/归母 ≥85%；③ 扣非同比 >0；④ 单季年化PE < 扣非PE（四条同时满足） | 0 |
| **明显高估** | ① 3 年分位 >70% 或全历史分位 >70%；或 ② 正常化PE >3× 扣非PE；或 ③ 扣非PE >80 倍且扣非增速 <30% | −2 |
| **合理** | 以上都不满足 | −1 |

**估值调整只能为 0、−1、−2，永远不能为正。** 无单季数据时，④ 用 TTM 替代并注明。

### 5.5 三情景估值

- 必须使用 `tools/financial_rigor.py three-scenario` 精确计算，禁止心算。
- 三情景必须写清业务假设；价格区间是纪律，不是预测。
- 报告必须给出：买入区间、观察区间、合理区间、高估区间；以及首批/加仓触发价。

### 5.6 仓位映射（"买多少"）

| 最终星级 | 仓位层级 | 占主题仓位 | 备注 |
|---|---|---|---|
| ★★★★★ | 核心仓位 | 50–60% | 质量 + 估值 + 周期同时满足 |
| ★★★★☆ | 卫星仓位 | 25–35% | 质量够，估值或周期有一项打折 |
| ★★★☆☆ | 观察名单 | 0% | 质量够但价格/周期不对 |
| ★★☆☆☆ | 高风险期权 | 5–15% | **只能来自 A 通道**，质量层 <3.5，须写明赌什么 |
| ★☆☆☆☆ | 不推荐 | 0% | — |
| ETF 替代 | — | 可替代全部 | 不想选股时使用 |

> **★★ 期权仓位的双重门槛**：必须是 A 通道 **且** 质量层 <3.5（A3）。A1/A2 因估值下调落到 ★★ 的，按观察处理（0 仓位），不得转成期权仓位。

**四条硬约束**：

1. B 通道一律 0 仓位，不得用"期权仓位"绕过质量门槛。
2. 核心仓位不得为空却被卫星仓位填满——没有标的通过核心条件，就空着，把仓位让给 ETF 或现金。
3. 每只标的必须标注周期档位 + 库存三指标 + 推荐度，推荐度必须按第六章公式算出，**不得手写**。
4. 行业整体质量层不达标时，结论是"不配置"；即便行业在周期底部、估值极低，结论也不变。

## 六、推荐度合成

> **最终星级 = min（质量层上限 − 估值调整，周期封顶）**

| 最终星级 | 含义 |
|---|---|
| ★★★★★ | 核心仓位候选（质量 + 估值 + 周期同时满足） |
| ★★★★☆ | 卫星仓位候选 |
| ★★★☆☆ | 观察名单（质量够但价格不够，或周期位置不对） |
| ★★☆☆☆ | 高风险期权（质量不足，只能小仓位赌变化；仍须 A 通道） |
| ★☆☆☆☆ | 不推荐 |

### 四条不能违反的规则

1. **估值便宜不能把推荐度打到质量层上限之上；周期好也不能。** 低估值与低库存只是"便宜"和"时点"，改变不了生意质量。
2. **质量层 ≥★★★☆ 的公司在明显高估时可以被下调到 ★★★☆☆ 观察**——但这是"什么时候买"的问题，不是"要不要买"的问题；报告必须分开表述。
3. **质量层 ≤★★ 且通过 A 通道的，最多只能进期权仓位；B 通道一律 0 仓位。**
4. **最终星级必须由表格逐项推导，禁止手写。**

## 七、报告输出规范

### 7.1 行业研究

开篇三张表，顺序固定：

1. 环节级生意质量排序（定价权来源 + 生意质量★）
2. 质量门槛通过/未通过名单（A/B 通道 + A1/A2/A3）
3. 被排除的便宜货

结论段先回答"有没有好生意"，再回答"价格和周期合不合适"，顺序不能反。

### 7.2 公司研究

报告必须分成两段独立结论：

- **第一段：是否值得跟踪。** A/B 通道 + 质量层 + 推荐度上限。这一段不看估值、不看周期。
- **第二段：什么时候买、买多少。** 周期档位 + 估值调整 + 最终星级 + 仓位 + 触发价。这一段不能改变第一段的结论。

必须包含：质量门槛表、护城河表、周期表、四锚点估值表、三层打分推导表。

### 7.3 团队研究

最终报告用三层打分表替代"四维平权 X/5"：

| 维度 | 结论 |
|---|---|
| 质量层（生意★ + 护城河★）÷2 | → 上限 |
| 估值状态与调整 | → −N |
| 周期档位与封顶 | → 封顶 N★ |
| **最终星级** | **min（上限 − 调整，封顶）** |

四大师的四维分析保留为证据，但**不再做算术平均**。

### 7.4 漏斗筛选

- **估值不进初筛。** PE 高低不是"是否值得跟踪"的标准。
- 初筛只用：6 条淘汰指标 + 1 条观察指标 + 护城河 ≥★★★。
- 周期只做"顶部封顶 + 不新建仓"，不做"底部加分"，也不取消跟踪资格。
- 估值只在终选后定价格区间和仓位。

### 7.5 买入 Checklist

七关顺序固定：

1. 能力圈
2. 好生意（生意质量）
3. 护城河
4. 管理层
5. 周期
6. 价格与安全边际
7. 仓位与决策纪律

周期在质量之后、价格之前；周期顶部一票否决。

---

## 八、禁止事项（红线）

1. 用低 PE 作为"值得跟踪"的理由。
2. 用周期底部作为"值得跟踪"的理由。
3. 用估值或周期把推荐度打到质量层上限之上。
4. 给 B 通道公司做估值或给任何仓位（包括期权仓位）。
5. 用四维平权、算术平均或手写星级代替三层打分。
6. 用同行 PE 绝对值代替自身历史分位。
7. 用周期顶部的利润算 PE 并称"便宜"。
8. 库存低就认定买点，不查订单与需求。
9. 单季用累计数或不差分。
10. 最终星级手写，不列推导。
